## 👋 About

Personal single-page developer portfolio of Yasir Arafat, a MERN stack developer and competitive programmer based in Dhaka, Bangladesh.

## ✨ Features

- Single-page layout covering projects, skills, and contact information
- Scroll and intro animations powered by GSAP
- Responsive design built with Tailwind CSS
- SEO setup using Next.js Metadata API, JSON-LD `Person` schema, `sitemap.ts`, and `robots.ts`

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** GSAP
- **Deployment:** Vercel

## 🚀 Getting Started

```bash
git clone https://github.com/arafatYasir/Portfolio.git
cd Portfolio
npm install
echo "NEXT_PUBLIC_SITE_URL=http://localhost:3000" > .env
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
